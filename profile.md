## 🎯 Mô Tả Ngắn Gọn

Website landing page chuyên nghiệp cho công ty xây dựng và thiết kế nội thất Mộc Đức với hơn 15 năm kinh nghiệm. Dự án tập trung vào việc giới thiệu doanh nghiệp, showcase portfolio và tối ưu hóa việc thu thập leads khách hàng.

---

## 🛠️ Công Nghệ Sử Dụng

### Frontend
- **React 19.1.1** + **TypeScript 5.8.3** - Core framework
- **Vite 7.1.0** - Build tool và development server
- **TailwindCSS 4.1.11** - CSS framework cho responsive design
- **React Router DOM 7.8.0** - Client-side routing
- **Framer Motion 12.23.12** - Animation library
- **Axios 1.11.0** - HTTP client

### Backend Integration
- **WordPress REST API** - Content Management System
- **WordPress Custom Fields (ACF)** - Dynamic content management
- **Formidable Forms** - Contact form handling

### Architecture
- **MVVM Pattern** - Model-View-ViewModel architecture
- **Component-based Architecture** - Reusable UI components
- **Service Layer Pattern** - API abstraction layer

---

## 🏗️ Kiến Trúc Dự Án

```
📁 Project Structure
├── 🎨 Components/ (UI Components)
├── 📊 Models/ (Data Types & Interfaces) 
├── 🔄 ViewModels/ (Business Logic & State)
├── 🌐 Services/ (API Integration)
├── 📄 Views/ (Page Components)
├── 🛠️ Utils/ (Helper Functions)
└── 🔧 Configs/ (App Configuration)
```

### Kiến Trúc MVVM
- **Model:** Định nghĩa cấu trúc dữ liệu từ WordPress API
- **View:** Components UI thuần túy, không chưa logic phức tạp
- **ViewModel:** Quản lý state, business logic và API calls
